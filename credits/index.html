Earth imagery

NASA Blue Marble Next Generation (2005). The app's daylight map uses twelve monthly 2004 composites. This website's animated map uses an August 2004 derivative from that set. Credit: NASA Earth Observatory; Blue Marble Next Generation produced by Reto Stöckli, NASA Earth Observatory.

NASA Black Marble 2016. The night maps are derived from NASA Black Marble 2016. Credit: NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Román, NASA GSFC.

Atlas Time resizes and color-grades these source images and uses them consistently with NASA's Images and Media Usage Guidelines. NASA does not endorse Atlas Time. No NASA insignia, logotype, identifier, or other mark is used as Atlas Time branding.
